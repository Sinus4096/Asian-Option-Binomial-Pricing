# European Floating-Strike Asian Call Option Pricing

## Overview

This repository contains a mathematical model and codebase for pricing a European floating-strike Asian call option. This project was originally designed as part of the "Stochastic Methods in Finance" course. The primary goal is to build and implement a multi-period binomial tree model to establish the arbitrage-free price of the option. To validate these results and improve calculation efficiency, a normal distribution approximation is also developed.
